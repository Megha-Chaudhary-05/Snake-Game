# 🐍 Snake Game in Python

## Overview
This is a simple implementation of the classic Snake Game using Python and the `turtle` library. The player controls a snake that grows longer as it eats food. The game ends if the snake collides with the wall or itself.

## Features
- Real-time gameplay using `pygame`
- Score tracking
- Game over and restart functionality
- Classic snake movement and growth

## Tech Stack
- **Language**: Python  
- **Library**: turtle
